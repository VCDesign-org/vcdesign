From v1

VCDesign v2 is not compatible with v1. Read v1 vocabulary and records as follows.

Source: implementation.md §6 "v1 からの移行". The table is the specification's, translated where it contains Japanese.

v1 vocabulary is used only on this page and in the archive. Every other page uses v2 vocabulary only.
