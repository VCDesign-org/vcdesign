1. Value Continuity

Value Continuity（価値の継続）とは、現在の価値をそのまま保存することではない。

変化や失敗があっても、次の価値を生み出せる状態を継続すること。

現在の業務、担当者、技術、製品が変わっても、次の価値生成に使えるものが残るなら、価値は継続している。

正本 README §1

正本が企画の段階で問うのは、次の一つです。

この取り組みは、良い結果を次の価値へつなげながら、悪い結果の連鎖を止められるか。

2. Value Asymmetry Principle

Upside は伝播可能にする。Downside は伝播させない。

良い結果と悪い結果を同じように扱わない。

  • 良い結果は、再利用・接続・学習によって次の価値へつながる道を開く。
  • 悪い結果は、境界・上限・復旧によって、それ以上広がらないようにする。

「伝播可能にする」とは、良い結果が次へ広がれる道を開いておくことであり、自動的に広げることではない。実際に広げるかどうかは、判断（Expand）で決める。

下を閉じる能力は、上に賭け続けるための原資である。

正本 README §2

3. Δ（期待との差）

Δ とは、取り組みの開始時に宣言した期待と、実際に起きたこととの差である。ここでいう期待は、前提としていた条件と、生み出そうとしていた価値の両方を含む。

  • 期待を下回る方向の差を Negative Δ と呼ぶ。伝播させない。
  • 期待を上回る方向の差を Positive Δ と呼ぶ。伝播可能にする。観測と保有は止めず、広げるかどうかは判断で決める。
正本 README §2「Δ（期待との差）」

VCDesign は、この一般的な意味を受けたうえで、Δ の基準線・向き・扱いを実装概念として定めています（芯：Δ）。

4. 5つの原則

Value Asymmetry Principle は、次の5つの原則として実践されます（正本 README §3 より引用）。

原則正本の言葉
1. 残す業務・担当・技術が変わっても残るものを、先に決める。標準、判断根拠、データ、接続、技能。保有し続ける人のいないものは残らない。
2. 見つける平均的な改善量ではなく、再利用によって大きく広がる兆候を見る。二回目が安くなる。頼んでいない所から引き合いが来る。別の判断の材料になる。接続するほど一件あたりの価値が上がる。
3. 閉じる悪い広がりは予測せず、境界で止める。損失の上限を先に決め、失敗を局所化し、前提を境界で確かめ直し、単一点への依存を避ける。
4. 試す戻せる範囲で変更する。復旧・切替・撤退できる能力が、試せる回数を決める。
5. 伝える結論ではなく、根拠を次の判断へ渡す。受け取った側は、それを自分の文脈で再判断する。

この順番には意味がある。何を残すかを決めていなければ、広がる兆候は見つけられない。悪い広がりを止められなければ、再び試すことはできない。そして伝えた根拠は、次の取り組みで「残す」ものの起点になる。

正本 README §3

5. Decision

レビューの結果は点数ではなく、次の判断につなげます。判断は次の6語です（正本 README §8 より引用）。

判断正本の言葉
ProceedValue Continuityを満たしており、現在の構造・現在の規模で進められる。
ExpandUpsideの兆候が観測されており、Downsideの上限と復旧能力の範囲で、対象・規模・接続を広げる。平均的な効果が出ただけでは Expand の根拠にしない。
Limit価値はあるがDownsideの伝播範囲が広すぎるため、対象・権限・規模・期間などを限定する。
Reframe価値、対象、境界、前提のいずれかを再定義する必要がある。
Defer外部条件や判断材料が不足しており、現時点では確定しない。
Retire継続しても次の価値生成につながらず、終了する方がValue Continuityに適う。開始前の取り組みについては、開始しない判断を含む。

VCDesign での扱い（宣言の更新と次の状態）は判断のページにあります。

6. Review Output

正本を使って企画をレビューするときは、少なくとも次の5項目を出力します。各項目は ok / warning / blocking で示し、判定には必ず根拠を付けます（正本 README §9）。

  1. Upside — 何が次の価値へつながるか、何が再利用可能か、上振れの兆候は何か
  2. Downside — 最大損失は何か、どこまで伝播するか、どこで止められるか、復旧・撤退できるか
  3. Continuity — 業務・人・技術・製品が変わった後に何が残るか
  4. Asymmetry — Upside propagation と Downside containment が両立しているか
  5. Decision — 6語のいずれか

正本は、人間の企画判断だけでなく、AI による企画レビューの判定軸として使うことを意図しています。AI に渡すときの指示の例も正本にあります。

8. VCDesign との関係

Value Continuityは、経営判断、企画、組織設計、システム設計、運用設計など、それぞれの層で異なる方法によって実装される。個別の方法論は、この原則を満たすための手段であり、Value Continuityそのものではない。

VCDesign（Value Continuity Design）は、そのうち特に 判断と責任 の面からValue Continuityを実装する方法論として位置づける。

正本 README §10「Implementation Boundary」

VCDesign がどの仕組みで各原則を実装しているかは、芯：5原則ごとの実装にまとめています。
